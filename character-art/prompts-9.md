## 附：批量生成命令（CLI 5.0Pro）

```bash
# 单张示例
dreamina text2image \
  --prompt="<上方提示词>" \
  --ratio=2:3 \
  --resolution_type=2k \
  --model_version=5.0Pro \
  --generate_num=1 \
  --poll=120 \
  --session=0
```

结果用 `dreamina query_result --submit_id=<id> --download_dir=<目录>` 下载；
`query_result` 返回的 `image_url` 是预览链接，**必须用 `--download_dir` 才能落盘**。
